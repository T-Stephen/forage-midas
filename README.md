### 🚀 Executive Summary

Developed in alignment with **JPMorgan Chase & Co.** advanced software engineering standards, the **Midas** architecture is a high-performance financial data visualization tool. This project demonstrates enterprise-level engineering capabilities by interfacing with live trading data feeds, patching critical backend system vulnerabilities, and engineering a dynamic frontend interface capable of parsing complex stock market metrics in real-time.

### ⚙️ System Architecture

* **Financial Data Feed (Backend):** A robust Python-based server architecture engineered to handle, process, and broadcast live stock market data streams without interruption.
* **Enterprise Dashboard (Frontend):** A highly optimized React and TypeScript framework designed to visualize trading anomalies, calculate data ratios, and track price fluctuations with sub-second latency.
* **System Optimization:** Refactored core codebase logic to ensure high availability and continuous data integration for institutional-grade financial tracking.

### 🛠️ Local Deployment (Quick Start)

To initialize the trading data environment on your local machine:

```bash
# 1. Clone the repository
git clone [https://github.com/T-Stephen/Midas.git](https://github.com/T-Stephen/Midas.git)
cd Midas

# 2. Initialize the Financial Data Feed (Backend)
cd datafeed
python server3.py

# 3. Initialize the Enterprise Dashboard (Frontend in a new terminal)
cd ../src
npm install
npm start
